# Welsh review checklist

All Welsh in `content/gair-wrth-air/` was written from memory by an AI model and has **not** been checked by a fluent speaker. Review before any public announcement.

## How to review

1. Read each page in `dist/` (or the deployed site) and mark each section below.
2. Fix entries directly in `content/gair-wrth-air/packs/cy/pages/<slug>.json`, or open a "Welsh correction" issue.
3. Record the reviewer and date in the table at the end.
